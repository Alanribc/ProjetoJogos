Nesse projeto, desenvolveremos um jogo em Java com o framework LibGDX. A ideia é fazer um jogo que funcionaria utilizando um IoT de pedais, onde quando eles fossem acionados, aconteceria uma ação dentro do jogo.  

Jogo: Escape do Labirinto  
Tema: O jogador deve escapar de um labirinto com armadilhas, inimigos e plataformas para pular, com objetivo de procurar a saída.  
Mecânica: O personagem deve saltar de plataforma em plataforma, evitar buracos e lutar ou se livrar de inimigos. O objetivo é encontrar a chave para escapar do labirinto antes que o tempo acabe.
